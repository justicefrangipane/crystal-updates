# Crystal preview downloads

**Current preview: [Build 80](https://github.com/justicefrangipane/crystal-updates/releases/tag/build-80)** — compact controls and easier trial setup for Windows.

[Download for Windows](https://github.com/justicefrangipane/crystal-updates/releases/download/build-80/Crystal-Build-80-Setup.exe) · [Installer ZIP](https://github.com/justicefrangipane/crystal-updates/releases/download/build-80/Crystal-Build-80-Setup.zip) · [Release notes](https://github.com/justicefrangipane/crystal-updates/releases/tag/build-80)

No GitHub sign-in is required. Setup selects x64 or ARM64 automatically, including Surface Pro 11, and preserves saved computer approvals and account state. First use offers **3 days without email**; initial activation needs internet. Confirming email extends that same trial to **7 days total**. Existing account dates stay the same across personal devices. Updates and repeat sign-in do not restart the trial. No card or automatic charge; purchasing is not available yet. At expiry, remote use stops while saved computers and files remain.

**Known email-delivery issue:** Microsoft can quarantine confirmation messages. Microsoft Support is investigating; delivery is not fixed by this release. New users can start the no-email trial. Existing expired trials are not reset. This is a preview offered while that issue remains open.

Build 80 includes the compact This computer card, aligned Advanced touch switch, smaller Welcome/Account dialogs, clearer resend/cancel/status controls and deliberate floating session-menu activation. Advanced touch explains the one-time Windows approval needed by some apps. See the [cumulative Bassem handoff](https://github.com/justicefrangipane/crystal-updates/releases/download/build-80/BUILD-80-BASSEM.md) for Apple integration and validation limits. No Apple app is included.

Both Windows architectures compiled and 169 installer checks passed. Build 80 is installed on the ASUS with saved approvals and the Cintiq display baseline preserved. Surface/iPad Build 80 behavior has not been physically accepted. Protected touch, capture, transport and recovery components are retained. ARM64 viewing/transport are native; incoming desktop sharing uses x64 compatibility and remains experimental. Forwarded controllers still require a compatible virtual-controller driver separately.

This is an unsigned development preview, not a Microsoft Store release.
