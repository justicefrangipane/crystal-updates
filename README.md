# Crystal preview downloads

**Current preview: [Build 75](https://github.com/justicefrangipane/crystal-updates/releases/tag/build-75)** — a seven-day verified-email trial for Windows. Install, then confirm your email inside Crystal. Use the same email on your personal Windows computers to keep one expiry date. Updating or signing in again does not restart the trial.

[Download for Windows](https://github.com/justicefrangipane/crystal-updates/releases/download/build-75/Crystal-Build-75-Setup.exe) · [Installer ZIP](https://github.com/justicefrangipane/crystal-updates/releases/download/build-75/Crystal-Build-75-Setup.zip) · [Release notes](https://github.com/justicefrangipane/crystal-updates/releases/tag/build-75)

No GitHub sign-in is required. Setup automatically selects x64 or ARM64 and preserves saved computer approvals. No card, automatic charge or checkout. When the trial ends, remote use stops; saved computers and files remain. Purchasing is not available yet.

Build 75 adds an automatic low-memory warning beside the session information. Update both Windows computers to use it. It reports sustained memory pressure on the computer running your apps, clears after recovery, and never closes apps automatically. iPhone/iPad warning support requires the corresponding Apple update; [Bassem's handoff](https://github.com/justicefrangipane/crystal-updates/releases/download/build-75/BUILD-75-BASSEM.md) documents integration and tests. This release does not contain an Apple app or establish Apple trial integration.

Email sign-in is easier to find: choose **Sign in** at the top, enter your existing trial email, then confirm the message. No password is required. A rate-limit countdown prevents repeated sends. The proposed three-day trial without email is not enabled yet; this update retains the seven-day verified-email trial and does not change email delivery.

Protected Artist Pad touch needs one local Windows approval on the computer running Artist Pad; normal updates reuse it. Physical-controller forwarding from Build 74 is retained. A compatible virtual-controller driver is a separate requirement. No game settings or graphics drivers are changed by the installer. Trial, protected touch, network transport and physical-display recovery binaries are unchanged from Build 74. Physical acceptance of the new warning remains pending. On Windows 11 ARM, viewing and transport are native ARM64; incoming desktop sharing uses x64 compatibility and remains experimental.

This is an unsigned development preview, not a Microsoft Store release. Use [Crystal-Build-75-Source.zip](https://github.com/justicefrangipane/crystal-updates/releases/download/build-75/Crystal-Build-75-Source.zip) for matching application source and notices; GitHub's automatic source ZIP contains only this distribution repository. [Checksums](https://github.com/justicefrangipane/crystal-updates/releases/download/build-75/SHA256SUMS.txt) accompany the files. `preview.json` offers verified public installer assets.
