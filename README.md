# Crystal preview downloads

**Current preview: [Build 72](https://github.com/justicefrangipane/crystal-updates/releases/tag/build-72)** — a seven-day verified-email trial for Windows. Install, then confirm your email inside Crystal. Use the same email on your personal Windows computers to keep one expiry date. Updating or signing in again does not restart the trial.

[Download for Windows](https://github.com/justicefrangipane/crystal-updates/releases/download/build-72/Crystal-Build-72-Setup.exe) · [Installer ZIP](https://github.com/justicefrangipane/crystal-updates/releases/download/build-72/Crystal-Build-72-Setup.zip) · [Release notes](https://github.com/justicefrangipane/crystal-updates/releases/tag/build-72)

No GitHub sign-in is required. Setup automatically selects x64 or ARM64 and preserves saved computer approvals. Existing preview users must also verify their email after this update. No card, automatic charge or checkout. When the trial ends, remote use stops; saved computers and files remain. Purchasing is not available yet.

**New iPhone/iPad pairing awaits an Apple update.** Some Apple builds reject the compact QR link. This release is the Windows trial and does not include an Apple app or Apple trial integration.

The optional protected Artist Pad touch helper needs one local Windows approval on the computer running Artist Pad; normal updates reuse it. Build 72 passed ASUS email activation and the user's Surface-to-ASUS touch and X-close Cintiq restoration check. Exact Build 72 ARM64 installation and real video-stream expiry remain pending. On Windows 11 ARM, the viewer and transport are native ARM64; incoming desktop sharing uses x64 compatibility and remains experimental.

This is an unsigned development preview, not a Microsoft Store release.
