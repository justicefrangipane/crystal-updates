# Crystal preview downloads

**Current preview: [Build 74](https://github.com/justicefrangipane/crystal-updates/releases/tag/build-74)** — a seven-day verified-email trial for Windows. Install, then confirm your email inside Crystal. Use the same email on your personal Windows computers to keep one expiry date. Updating or signing in again does not restart the trial.

[Download for Windows](https://github.com/justicefrangipane/crystal-updates/releases/download/build-74/Crystal-Build-73-Setup.exe) · [Installer ZIP](https://github.com/justicefrangipane/crystal-updates/releases/download/build-74/Crystal-Build-73-Setup.zip) · [Release notes](https://github.com/justicefrangipane/crystal-updates/releases/tag/build-74)

No GitHub sign-in is required. Setup automatically selects x64 or ARM64 and preserves saved computer approvals. Existing preview users must also verify their email after this update. No card, automatic charge or checkout. When the trial ends, remote use stops; saved computers and files remain. Purchasing is not available yet.

**New iPhone/iPad pairing awaits an Apple update.** Some Apple builds reject the compact QR link. This release is the Windows trial and does not include an Apple app or Apple trial integration.

The optional protected Artist Pad touch helper needs one local Windows approval on the computer running Artist Pad; normal updates reuse it. Build 74 restores physical-controller forwarding while keeping the on-screen gamepad removed. The exact companion was tested with Kena on an iPad mini; controller input and full-screen gameplay worked. A compatible virtual-controller driver is required on the computer running the game; this package does not install one. The ASUS uses separately installed ViGEmBus 1.22.0. Game settings are not changed by the installer. Protected touch, trial and display-recovery binaries are unchanged. The full Build 74 installer and its Surface behavior have not yet been physically tested. On Windows 11 ARM, the viewer and transport are native ARM64; incoming desktop sharing uses x64 compatibility and remains experimental.

This is an unsigned development preview, not a Microsoft Store release. Use [Crystal-Build-73-Source.zip](https://github.com/justicefrangipane/crystal-updates/releases/download/build-74/Crystal-Build-73-Source.zip) for matching application source and notices; GitHub's automatic source ZIP contains only this distribution repository.
